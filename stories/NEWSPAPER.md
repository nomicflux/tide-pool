# Tomorrow's paper

The newspaper seller has tomorrow's paper. Below the date is a space
for the days the sea has already lived.

```text
diary
```

The front page has space for one thing that has not happened yet.

```text
bottle tomorrow the sea will return a borrowed name
bottle tomorrow someone will leave the door open
tide
ask tomorrow
```

Read the answer as the morning headline. If you want the next visitor to
receive it, type `cast` followed by the words you choose.

The seller folds the paper into a boat. It knows no more about tomorrow
than you do.
