# Names must be returned by morning

The counter is covered in little paper tags. The borrowed names
have soft edges.

```text
bottle a name left drying beside the door
bottle a name that still answers to the sea
tide
trace name
```

The clerk asks which one is yours. You may type `bottle` followed by a name
you are ready to leave here, or let the clerk keep the question.

```text
tide
ask name
```

Read the answer as the writing on your tag.

The clerk puts it on a hook. You step outside before anyone calls you back.
