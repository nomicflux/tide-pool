# The path back

The path looks different from this end. You have brought back the same shoes,
but something has been walking in them ahead of you.

```text
drop footprint gate return
tide
shells 3
```

These are the shore's latest poems, up to three. On a new shore there is only
the one you just left. On an older shore, look for a word that seems to have
been waiting for you.

You may type `bottle` followed by that word. Continue with an empty Enter.

```text
echo
tide
shells 3
```

Read the newest poem beside the others. What crossed over? What stayed on
the far side?

```text
bind
```

The book keeps the longer path. Open it if you want to walk further back.

The gate opens both ways.
