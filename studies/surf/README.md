# Six words, four seas

Moon, lantern, salt, window, rain, home: the same words in the same order.
The weather changes the pace and the surf beneath their bells. In the ice
postcards, the words and shoreline hold still. Day and night keep the same
words, layout, and sound; daylight changes the water and ink.
