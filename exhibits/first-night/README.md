# First night

Six bottled memories passed through calm, storm, and fog.

- [Read the three poems](book.html), or [their plain-text shore](shore.txt).
- [See the pool in fog](postcard.svg).
- [Hear its six bells](tide.wav).

The first line the sea gave back was:

> the room we left behind shelters the last train home

All six memories remained in the water through all three tides.

Make another version: run `python3 tidepool.py stories/FIRST_NIGHT.md` from
the project folder, or use `read first_night` in the browser. The
[score](../../stories/FIRST_NIGHT.md) keeps the memories; the sea chooses new pairings.
