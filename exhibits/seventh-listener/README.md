The sea's last words were:

> a name returned in time to hear midnight shelters a new page with room for both keepers

The name [left at the counter](../name-return/README.md) heard
[the new page open](../first-page/README.md). Alice answered with tide 47
and signed the guestbook beside Bob for 7 November. The lamp says “listening”.
