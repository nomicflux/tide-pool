The first line the sea gave was:

> I found the kettle warm and left the lamp lit for you dreams of a cup set beside the lamp

Alice cast “the kettle is on whenever you come back” into the live sea.
Bob found it and cast a reply. Alice found that reply and set a cup beside it.
